overtpsyops-frame-check

Local drag-and-drop & upload interface for pixel, cadence, and alignment analysis.

Local PowerShell required for full analysis: Extract ZIP, run python -m pip install -r requirements.txt then python server.py, and open http://127.0.0.1:8765.

Drag & drop a local video file here, or click to choose a file

Processed locally on your machine—nothing is uploaded to external servers.
